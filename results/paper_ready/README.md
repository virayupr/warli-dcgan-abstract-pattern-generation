# Paper-ready enhancement results

This directory contains compact, submission-facing outputs from the complete
three-seed epoch-100 analysis. Values summarize seeds 42, 123, and 2024.

## Key results

| Diagnostic | DCGAN | WGAN-GP |
|---|---:|---:|
| Axial symmetry at tau = 0.55 | 0.8313 +/- 0.0144 | 0.8652 +/- 0.0116 |
| LPIPS nearest-neighbour distance | 0.2179 +/- 0.0162 | 0.1972 +/- 0.0068 |
| Inception cosine NN distance | 0.3526 +/- 0.0133 | 0.3238 +/- 0.0129 |

Lower learned-feature nearest-neighbour distance means greater proximity to
the training collection in that representation. These diagnostics do not by
themselves prove memorization or novelty.

The `tables` directory includes architecture and per-seed summaries. The
`figures` directory includes threshold-sensitivity plots, learned-feature
retrieval examples, connected-component plots, and foreground-mask
diagnostics. White regions in the mask diagnostics must correspond to the
Warli foreground before the threshold-dependent results are interpreted.

Raw generated arrays and checkpoints are not included because of their size.
They are regenerated by `notebooks/warli_multi_seed_pipeline_FINAL_COLAB.ipynb`.
